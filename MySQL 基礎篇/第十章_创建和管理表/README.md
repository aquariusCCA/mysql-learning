# 第十章_创建和管理表

这一章开始从“会查询数据”进入“会定义数据结构”。

前面几章主要集中在 `SELECT`、函数、聚合与子查询，重点是把既有数据查出来、筛出来、算出来；到了这一章，重点会转成：

> 资料还没查之前，要先决定它怎么被存。  
> 也就是先定义数据库、数据表、字段、约束与结构规则，再谈后续的插入、更新、查询与维护。

创建和管理表不是单纯记住 `CREATE TABLE` 的语法，而是先建立一套更稳定的判断顺序：

1. 这份资料应该放在哪个数据库里？
2. 这张表要表达什么业务对象？
3. 这一列到底存什么资料？
4. 该用哪一种数据类型？
5. 名称怎么命名才不会混乱？
6. 后续查询、更新、关联时，这样的设计是否容易维护？

目前这一章已整理出 `8` 篇笔记，先把建表前的基础观念、数据库层级操作、建表起手语法、表结构修改、表名调整、删除操作、清空资料操作与实务补充收拢起来，包含：

- 一条数据在 MySQL 中的存储过程；
- 数据库服务器、数据库、数据表、行与列的层级关系；
- 标识符命名规则；
- MySQL 常见数据类型总览；
- 数据库的创建、查看、切换、修改与删除；
- 直接建表、查询结果建表与表结构查看方式；
- 既有表结构的追加、修改、改名与删除；
- 表名修改的两种主要写法与使用场景；
- 删除表时的语法、风险与依赖检查；
- `TRUNCATE`、`DELETE`、`DROP` 三者的差异与选择方式；
- 命名规范、操作风险意识与 MySQL 8 DDL 原子化补充。

## 本章在整体学习地图中的位置

- 前面的查询章节解决“怎么把资料查出来”。
- 这一章开始解决“资料一开始该怎么存进去”。
- 如果建表阶段的字段命名、类型选择、结构设计没处理好，后面的查询、统计、维护都会越来越难写。

可以把这一章理解成：

> 从“使用既有资料”过渡到“定义资料结构”的起点章节。

## 本章学习目标

学完目前已整理的内容后，至少应能做到：

- 说出一条数据进入 MySQL 的基本流程。
- 理解数据库服务器、数据库、数据表、行与列之间的层级关系。
- 知道数据库名、表名、字段名的基本命名限制。
- 知道保留字冲突时要如何处理。
- 对整数、字符、浮点、定点数、日期、文本、二进制等常见类型先建立整体印象。
- 知道最常用的数据库管理命令该怎么写、什么时候用。
- 知道 `CREATE TABLE` 的两类常见建表方式，以及建表后如何检查表结构。
- 知道 `ALTER TABLE` 常见能处理哪些结构变更，以及不同子句的基本区别。
- 知道重命名表时该如何在 `RENAME TABLE` 与 `ALTER TABLE ... RENAME` 之间做选择。
- 知道 `DROP TABLE` 会删除什么、什么时候该加 `IF EXISTS`，以及删除前要检查哪些风险。
- 知道清空资料时，`TRUNCATE TABLE`、`DELETE FROM` 与 `DROP TABLE` 在结构保留、事务、自增与速度上的差异。
- 知道这一章对应的实务补充：字段命名规范、结构操作前的备份意识，以及 MySQL 8 DDL 原子化的大意。

## 建议阅读顺序

### 1. [1 基础知识](./1%20基础知识.md)

先建立建表前的共同基础。

这一篇重点是：

- 一条数据在 MySQL 中是如何一步一步被存储的；
- 为什么要先有数据库，再有数据表；
- 标识符命名时有哪些基本限制；
- 常见数据类型大致可以分成哪些类；
- `CHAR`、`VARCHAR`、`FLOAT`、`DOUBLE`、`DECIMAL`、`TEXT`、`BLOB` 这些类型各自适合什么场景。

适合刚进入建表章节，或准备开始写 `CREATE TABLE` 前先回查。

### 2. [2 创建和管理数据库](./2%20创建和管理数据库.md)

在开始操作资料表之前，先把数据库层级的基本操作学会。

这一篇重点是：

- 如何创建数据库；
- 如何指定字符集；
- 如何查看当前所有数据库与当前正在使用的数据库；
- 如何查看指定数据库中的数据表；
- 如何切换数据库；
- 如何修改数据库字符集；
- 如何删除数据库，以及为什么 `IF EXISTS` / `IF NOT EXISTS` 更稳妥。

适合准备开始写建表语句，或想快速回查数据库层级命令时阅读。

### 3. [3 创建表](./3%20创建表.md)

正式进入“定义一张表”的起手页。

这一篇重点是：

- `CREATE TABLE` 的基本语法；
- 建表时哪些项目必须指定；
- 如何直接按字段定义建立资料表；
- 如何用 `AS SELECT` 把查询结果直接生成为新表；
- 如何用 `DESC`、`DESCRIBE`、`SHOW CREATE TABLE` 检查表结构。

适合准备开始写第一张表，或想快速回查建表语法与表结构检查方式时阅读。

### 4. [4 修改表](./4%20修改表.md)

进入“表已经建好，后续如何调整结构”的高频回查页。

这一篇重点是：

- 如何新增字段；
- 如何修改字段类型、默认值与位置；
- 如何重命名字段；
- 如何删除字段；
- 删除字段前为什么要先检查外键、索引与其他依赖。

适合开始进入表结构调整、重构既有表，或想快速比对 `MODIFY`、`CHANGE`、`DROP COLUMN` 时阅读。

### 5. [5 重命名表](./5%20重命名表.md)

处理“表结构没变，但名称要调整”的快速回查页。

这一篇重点是：

- `RENAME TABLE` 的用法；
- `ALTER TABLE ... RENAME` 的用法；
- 哪一种方式适合批量改名；
- 哪一种方式适合改名同时调整表结构。

适合想改表名、批量改表名，或想快速比较两种改名写法时阅读。

### 6. [6 删除表](./6%20删除表.md)

处理“整张表都不再需要”的高风险回查页。

这一篇重点是：

- `DROP TABLE` 的基本语法；
- `IF EXISTS` 的作用；
- 删除表会连哪些内容一起删掉；
- 外键依赖为什么会影响删除操作。

适合准备删除测试表、临时表或废弃表前快速确认风险时阅读。

### 7. [7 清空表](./7%20清空表.md)

处理“表还要保留，但资料想清空”的高频对比页。

这一篇重点是：

- `TRUNCATE TABLE` 的基本行为；
- `DELETE FROM` 的基本行为；
- 为什么两者在回滚、自增与速度上不同；
- `DROP TABLE`、`TRUNCATE TABLE`、`DELETE FROM` 该如何选择。

适合准备清空测试资料、批次重置资料表，或想快速区分三种删除层级时阅读。

### 8. [8 内容拓展](./8%20内容拓展.md)

作为第十章收尾的补充页，把规范、风险与版本差异放在一起整理。

这一篇重点是：

- 阿里巴巴《Java开发手册》里的 MySQL 字段命名建议；
- 为什么清空表、删表、改表前要先有风险意识与备份习惯；
- MySQL 8 的 DDL 原子化在实务上解决了什么问题。

适合学完本章基础语法后，用来补强实务判断与版本认知。
