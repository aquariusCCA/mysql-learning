# 第十二章_MySQL 数据类型精讲

这一章开始把“会建表”进一步推进到“字段到底该用什么类型”。

前面第十章已经先建立了数据库、数据表、字段与结构设计的基础观念；到了这一章，重点会转成：

> 表的结构大致知道了，但每一列到底该存成什么类型，才是后续查询、排序、计算、存储与维护是否稳定的关键。

数据类型不是单纯背名称，而是要先建立一套更稳定的判断顺序：

1. 这一列存的是整数、金额、时间、文本还是二进制资料？
2. 这份资料更重视范围、精度、长度还是存储空间？
3. 这列是否需要允许空值、默认值、自增或特定字符集？

目前这一章已整理出 `9` 篇笔记，先用总览页建立常见数据类型分类与字段属性的整体地图，再进入整数、浮点、定点数、位类型、日期时间、字符串、枚举与集合类型的选型重点。

## 本章在整体学习地图中的位置

- 前面的查询章节解决“怎么把资料查出来”。
- 第十章解决“数据库和数据表怎么定义出来”。
- 这一章开始解决“字段到底该选哪一种类型，定义时还要搭配哪些属性”。

可以把这一章理解成：

> 从“会写建表语法”过渡到“会为字段选对类型”的起点章节。

## 本章学习目标

学完目前已整理的入口内容后，至少应能做到：

- 知道 MySQL 常见数据类型大致有哪些分类。
- 对整数、浮点、定点数、字符串、日期时间、二进制、JSON、空间数据类型先建立整体印象。
- 知道字段定义时除了类型本身，还常会搭配 `NULL`、`DEFAULT`、`PRIMARY KEY`、`AUTO_INCREMENT`、`UNSIGNED`、字符集等属性。
- 知道这一章当前这篇笔记的用途是“总览”，适合先定位分类，再进入细节。

## 建议阅读顺序

### 1. [1 MySQL 中的数据类型](./1%20MySQL%20中的数据类型.md)

先建立第十二章的整体地图。

这一篇重点是：

- MySQL 常见数据类型有哪些大类；
- 每一类下面有哪些代表类型；
- 字段定义时常见的附加属性有哪些。

适合刚进入数据类型章节，或准备建表时先快速定位字段类型时阅读。

### 2. [2 整数类型](./2%20整数类型.md)

在有了总览之后，先进入最常见的一类字段。

这一篇重点是：

- `TINYINT` 到 `BIGINT` 的字节数与范围差异；
- `UNSIGNED` 到底影响什么；
- 为什么 `INT(M)` 不等于“最多 M 位数”；
- `ZEROFILL` 在旧版 MySQL 里的作用，以及为什么现代设计不建议继续依赖它。

适合准备定义编号、计数、年龄、库存、主键等整数字段时阅读。

### 3. [3 浮点类型](./3%20浮点类型.md)

接着处理“带小数但不一定要求完全精确”的数值类型。

这一篇重点是：

- `FLOAT` 和 `DOUBLE` 的精度与适用场景差异；
- 为什么浮点数会有精度误差；
- 为什么金额场景不该优先选浮点型；
- `FLOAT(M,D)` / `DOUBLE(M,D)` 为什么不建议继续依赖。

适合准备定义测量值、统计值，或想判断价格与金额是否该改用 `DECIMAL` 时阅读。

### 4. [4 定点数类型](./4%20定点数类型.md)

在看完浮点数之后，接着处理“必须精确到十进制”的数值类型。

这一篇重点是：

- `DECIMAL(M,D)` 里的 `M` 与 `D` 各代表什么；
- 为什么金额、价格、税额通常优先选 `DECIMAL`；
- `DECIMAL` 和 `FLOAT` / `DOUBLE` 的根本差异；
- 精确十进制表示带来的好处与代价。

适合准备定义金额、余额、单价、折扣率等字段时阅读。

### 5. [5 位类型：BIT](./5%20位类型：BIT.md)

接着补上比较特殊、但在状态压缩和位标志场景里很有用的位类型。

这一篇重点是：

- `BIT(M)` 的位数、范围与存储空间怎么理解；
- `BIT(1)`、`BIT(5)`、`BIT(64)` 分别适合什么；
- `BIT` 和 `BOOLEAN` / `TINYINT(1)` 的差别；
- 为什么查询 `BIT` 字段时常需要配合 `BIN()` 或 `HEX()`。

适合准备表示布尔开关、权限位、状态位时阅读。

### 6. [6 日期与时间类型](./6%20日期与时间类型.md)

最后补上业务表里几乎一定会出现的日期时间类型。

这一篇重点是：

- `YEAR`、`DATE`、`TIME`、`DATETIME`、`TIMESTAMP` 各自存什么；
- `TIME` 为什么不只是“几点几分几秒”；
- `DATETIME` 和 `TIMESTAMP` 的区别；
- 业务固定时间与系统记录时间该怎么选型。

适合准备定义生日、会议时间、预约时间、创建时间、更新时间等字段时阅读。

### 7. [7 文本字符串类型](./7%20文本字符串类型.md)

最后补上建表里最常见的一大类字段：字符串。

这一篇重点是：

- `CHAR`、`VARCHAR`、`TEXT` 系列各自适合什么；
- 固定长度与可变长度字符串的差别；
- 普通短字符串和大段文本该怎么切分；
- 为什么不是所有字符串都应该直接用 `TEXT`。

适合准备定义用户名、邮箱、地址、标题、文章正文等字段时阅读。

### 8. [8 ENUM 类型](./8%20ENUM%20类型.md)

最后补上“固定候选值单选字段”的特殊类型。

这一篇重点是：

- `ENUM` 适合什么字段；
- 为什么它适合稳定的小型单选集合；
- 定义顺序为什么会影响排序与行为理解；
- 什么情况下该改用普通字符串或字典表。

适合准备定义订单状态、性别、季节、等级等字段时阅读。

### 9. [9 SET 类型](./9%20SET%20类型.md)

最后补上固定候选值中的“多选版”类型。

这一篇重点是：

- `SET` 为什么适合稳定的小型多选集合；
- `SET` 和 `ENUM` 的差别；
- `SET` 的位标记式思路与存储空间理解；
- 什么情况下应改用关联表或字典表设计。

适合准备定义兴趣标签、权限开关、固定多选属性字段时阅读。

## 本章小节

- [1 MySQL 中的数据类型](./1%20MySQL%20中的数据类型.md)：整理常见数据类型分类与字段属性，作为后续理解各类型差异的总览入口。
- [2 整数类型](./2%20整数类型.md)：整理 5 种整数类型的范围差异、`UNSIGNED`、显示宽度与 `ZEROFILL`，作为整数字段选型入口。
- [3 浮点类型](./3%20浮点类型.md)：整理 `FLOAT`、`DOUBLE` 的精度差异、浮点误差与 `DECIMAL` 的使用边界，作为小数型字段选型入口。
- [4 定点数类型](./4%20定点数类型.md)：整理 `DECIMAL(M,D)` 的定义、金额场景的选型逻辑，以及它和浮点数的边界。
- [5 位类型：BIT](./5%20位类型：BIT.md)：整理 `BIT(M)` 的位数范围、显示方式，以及它和布尔值、位标志之间的关系。
- [6 日期与时间类型](./6%20日期与时间类型.md)：整理 `YEAR`、`DATE`、`TIME`、`DATETIME`、`TIMESTAMP` 的用途差异，以及业务时间与系统时间的选型方式。
- [7 文本字符串类型](./7%20文本字符串类型.md)：整理 `CHAR`、`VARCHAR`、`TEXT` 系列的适用边界，以及短字符串与长文本的选型方式。
- [8 ENUM 类型](./8%20ENUM%20类型.md)：整理 `ENUM` 的适用边界、内部顺序带来的行为，以及稳定单选集合的建模方式。
- [9 SET 类型](./9%20SET%20类型.md)：整理 `SET` 的适用边界、多选固定集合的建模方式，以及它与规范化设计的取舍。
